# Claudot Contribution Rules

- This repository is the Claudot engine fork of Godot.
- All branches, commits, and pull requests must target the Claudot repository.
- The default PR base repository is `godot-vibe-coding/claudot`.
- Never create pull requests against `godotengine/godot`.
- Use the `claudot` remote for pushing changes.
- Treat the official Godot repository as the upstream source only.
- Before creating a pull request, verify that its base repository is Claudot.
- Do not push directly to the official Godot repository.
